# ADR 0010：混合检索与上下文预算

- 状态：superseded（被 [0035](0035-memory-retrieval-v4.md) 取代）
- 关联：当前检索、排序与上下文预算契约见 [0035](0035-memory-retrieval-v4.md)

## 背景

语义检索不擅长精确标识符，关键词检索不擅长同义表达，Agent 上下文容量有限。

## 决策

关键词、语义、实体、关系和时间检索使用候选并集并统一排序。最终结果回到权威版本确认，并通过独立上下文装配应用预算。

## 影响

- 精确和语义查询互补。
- 需要统一排序和解释信号。
- 查询结果携带截断、索引状态和新鲜度。
- 任何索引都不能绕过生命周期和作用域过滤。
