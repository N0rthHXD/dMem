# ADR 0014：SQLite 扩展白名单

- 状态：accepted

## 背景

SQLite 扩展能够增加 FTS 和向量能力，也可能引入任意本地代码加载和不可控依赖。

## 决策

只允许编译时确定、版本固定、许可证已审查的 SQLite 能力和扩展。禁止通过 API、配置或网络加载任意动态扩展。

## 影响

- 第一阶段使用 SQLite 官方 FTS 等内建能力。
- 向量扩展需要单独技术验证。
- 扩展索引始终是可重建派生数据。

## 落地

0031 采用 sqlite-vec 作为首个被批准的编译期静态链接扩展：固定 `v0.1.6`，通过 `sqlite3_auto_extension` 随进程加载，不提供任何 API、配置或文件路径的动态加载通道。
