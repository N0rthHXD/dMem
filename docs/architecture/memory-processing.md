# dMeM 记忆处理设计

## 1. 处理目标

将不可变的原始事件转换为可检索、可解释、可修订的结构化记忆。处理结果必须保留来源，不得把模型输出直接视为无条件事实。

## 2. 处理流水线

```text
原始事件
  → 选择是否处理
  → 收集局部上下文
  → 提取候选记忆
  → 标准化和分类
  → 识别实体、时间和关系
  → 查找相关记忆
  → 去重和冲突检测
  → 生成新增或修订建议
  → 业务规则确认
  → 创建版本和证据
  → 生成索引任务
```

## 3. 处理选择

不是所有原始事件都必须产生长期记忆。选择依据可以包括：

- 输入类型。
- 来源配置。
- 空间和项目策略。
- 内容长度和敏感性。
- 是否已经处理过。
- 是否有明确的长期价值信号。
- 当前队列和资源预算。

选择结果：

```text
skip          仅保留原始事件
candidate     进入候选提取
reprocess     按新处理版本重新处理
```

## 4. 候选记忆

候选记忆至少包含：

```text
content
memory_type
space_id
valid_from
valid_until
confidence
source_event_ids
evidence_refs
extraction_method
processing_version
```

候选不直接进入默认检索。系统根据规则将其创建为 `candidate` 或 `active` 版本。

第一阶段手工创建和每次手工 revision 必须至少引用一条已存在的原始事件证据。纯手工事实先 ingest 一个 `source_type=manual` 的原始事件，再引用该事件创建记忆。

## 5. 提取上下文

提取可以使用：

- 当前原始事件。
- 同一会话最近事件。
- 当前任务上下文。
- 当前项目的高层摘要。
- 相关已有记忆。

提取上下文必须受大小预算约束。提取阶段使用的已有记忆只是辅助输入，不自动成为新记忆证据；证据必须明确绑定到原始事件或用户反馈。

## 6. 去重

去重分为三层：

```text
事件幂等去重：相同事件不重复保存
文本精确去重：相同内容不重复创建
语义候选去重：相似内容交给业务规则判断
```

语义相似不等于事实相同。语义去重只能产生合并建议，不能单独触发删除。

## 7. 冲突处理

候选记忆与已有记忆可能是：

```text
无关
重复
补充
替代
冲突
同一事实的不同时间状态
```

处理规则：

- 无关：创建独立记忆或忽略。
- 重复：关联已有记忆，不创建重复版本。
- 补充：创建新版本或关联记忆。
- 替代：新版本有效，旧版本标记 `superseded`。
- 冲突：保留双方，标记 `contested`，必要时进入人工确认。
- 时间变化：根据有效时间建立版本关系，不仅按写入时间判断。

第一阶段禁止模型直接物理删除旧记忆。撤回和删除必须通过明确的业务操作完成。

## 8. 处理失败

处理失败分类：

```text
transient_dependency
permanent_dependency
invalid_model_output
invalid_input
resource_exhausted
policy_rejected
```

- 原始事件始终保留。
- 临时依赖失败可重试。
- 非法模型输出应记录失败，不应伪装成“没有提取到记忆”。
- 处理规则或模型升级后可按版本重新处理。
- 重试必须使用幂等键。

## 9. 处理版本

每次处理记录：

```text
processing_version
model_identity
prompt_or_rule_identity
embedding_identity
created_at
```

处理版本变化时，旧版本继续作为历史依据，新的结果创建新的记忆版本，不覆盖原始事件。

## 10. 记忆层次

支持渐进式视图，但不要求每条数据经过全部层次：

```text
原始事件
  → 原子记忆
  → 场景或主题聚合
  → 长期画像或高层摘要
```

高层摘要必须能通过证据关系下钻到低层记忆和原始事件。摘要是派生的业务记忆版本，不能成为唯一事实来源。

## 11. 外部处理端口

模型、嵌入和重排能力通过抽象端口使用。处理端口应返回结构化结果和稳定错误分类，不直接写入 SQLite。

业务层负责：

- 验证结果结构。
- 绑定来源和处理版本。
- 执行冲突和生命周期规则。
- 在事务中提交权威版本。

## 12. 第一阶段处理策略

优先实现：

- 原始事件异步接收。
- 基础事实和偏好提取。
- 精确和有限语义去重。
- 候选、有效和争议状态。
- 证据绑定。
- 失败重试和重新处理。

暂不实现：

- 自动训练模型。
- 自动参数记忆。
- 未审核 Skill 执行。
- 模型自主永久删除历史。
