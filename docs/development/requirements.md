# dMeM 需求说明

## 1. 范围

dMeM 是由单个 Linux 系统用户拥有的本地常驻 daemon，为外部 Agent、应用和采集器提供长期记忆的接入、保存、形成、检索和管理能力。第一阶段采用 Go + SQLite，默认不开放网络访问。

第一阶段同一系统用户下的 Agent 视为可信调用方，但系统仍记录调用方、Agent、应用、项目和会话信息，用于作用域、来源、审计和未来隔离。

## 2. 使用场景

- Agent 提交对话、工具调用、任务结果和用户偏好。
- 采集器提交文件、项目和外部事件的变化。
- Agent 按当前项目、任务、时间和语义查询相关记忆。
- 用户或 Agent 查看、确认、纠正、归档和删除记忆。
- daemon 在后台从原始事件提取候选记忆并更新索引。
- daemon 重启、模型不可用或索引损坏后继续工作或明确降级。
- 用户导出、备份、恢复或删除指定空间中的数据。

## 3. 功能需求

### 3.1 数据接入

- 支持消息、对话、事件、工具调用、工具结果和文件引用等输入类型。
- 输入必须转换为统一原始事件。
- 每个事件必须有稳定事件标识或由 daemon 分配事件标识。
- 重复提交相同幂等键不得创建重复原始事件。
- 原始事件持久化成功后，才允许返回 `accepted`。
- 输入失败必须返回稳定错误类别，不得静默丢弃。

### 3.2 原始数据

- 保存原始内容、来源、角色、时间和作用域。
- 保存外部发生时间和 daemon 接收时间。
- 支持按事件、空间、来源和时间查询。
- 支持重放原始事件以重新执行记忆处理。
- 记忆提取失败不得删除原始事件。

### 3.3 结构化记忆

- 第一阶段支持事实、偏好、约束、决策、任务、事件、项目背景和 Agent 经验类型；关系记忆延期。
- 每条记忆有稳定逻辑身份和不可变版本。
- 每个版本可关联一个或多个原始证据。
- 支持候选、有效、争议、被替代、归档、过期、撤回和删除状态。
- 支持人工确认、纠正、补充、否认、冻结和恢复。
- 自动处理不得无历史地覆盖或物理删除已有事实。

### 3.4 检索

- 第一阶段支持结构化过滤和 SQLite FTS 关键词检索。
- 语义、实体、关系和高级时间检索按 [能力矩阵](../phase-1/scope.md) 延期。
- 检索必须按空间和作用域过滤。
- 检索必须确认权威记忆的当前版本和生命周期状态。
- 第一阶段支持最大条数和最大字符数；Token 预算延期。
- 结果包含记忆标识、版本、来源和必要解释。
- 派生索引不可用时提供明确降级结果。

### 3.5 异步处理

- 原始事件接收与记忆提取异步解耦。
- 处理任务必须持久化状态。
- 支持 lease、重试、超时、取消和 daemon 重启恢复。
- 队列必须有上限，过载时返回延迟或拒绝状态。
- 外部模型不可用时，原始数据仍可保存。

### 3.6 数据管理

- 支持单条记忆和空间范围的查看、修订、归档、恢复和删除。
- 支持索引重建。
- 数据导出和完整备份工具延期，不作为第一阶段验收。
- 删除操作必须定义原始内容、索引、缓存、任务、日志和备份的清除范围。

## 4. 非功能需求

### 4.1 持久性

- SQLite 是第一阶段权威数据和任务状态存储。
- 权威数据提交必须有明确事务边界。
- 派生索引可以重建，不能成为唯一数据来源。
- daemon 崩溃后能够检查数据库并恢复可恢复任务。

### 4.2 本地安全

- 默认仅允许当前用户访问本地服务端点。
- 默认不监听网络地址。
- 默认不发送遥测。
- 日志默认不包含原始内容和敏感凭据。
- 第一阶段不把 Agent 标识当作安全授权，但所有操作都记录调用方。

### 4.3 资源控制

- 限制请求大小、响应大小、任务队列、并发、CPU、内存、磁盘和临时空间。
- 磁盘接近耗尽时优先保留查询、删除和恢复能力。
- 外部模型调用必须受超时、重试和预算约束。

### 4.4 可观测性

- 提供进程、存储、查询、索引、任务队列、外部依赖和磁盘健康状态。
- 请求、事件、任务、记忆和版本之间可通过标识关联。
- 记录失败类别、重试次数、索引新鲜度和处理积压。

## 5. 第一阶段验收标准

- 重复提交同一事件不会产生重复原始事件。
- SQLite 事务中断不会产生“已确认但未保存”的写入结果。
- 外部模型不可用时，原始事件仍可查询并可稍后重试处理。
- 记忆修改不会破坏历史版本和证据关联。
- 删除后的记忆不再参与默认检索。
- FTS 检索可以独立工作，索引损坏时明确返回降级状态。
- daemon 重启后能恢复未完成任务。
- FTS 删除后能从当前投影重建。
- 查询结果不会跨越请求指定的项目或会话作用域。
- 所有异步操作都能通过任务标识查询最终状态。

## 6. 第一阶段不解决的问题

- 多用户共享和复杂 ACL。
- 参数记忆、模型训练和跨模型激活迁移。
- 完整通用知识图谱。
- 自动执行 Skill。
- 云端同步和默认远程发布。
