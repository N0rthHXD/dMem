# dMeM 隐私、保留与删除

## 1. 默认策略

- 数据保存在当前 Linux 用户的数据目录。
- 默认不开放网络访问。
- 默认不上传遥测。
- 默认不在日志中记录原始内容。
- 默认不将数据发送给外部模型，除非明确配置处理和外发策略。
- 第一阶段 Agent 全部可信，但所有操作保留调用方记录。

## 2. 数据分类

```text
raw_content       原始消息、工具结果和文件内容
derived_memory    结构化记忆和摘要
metadata          来源、时间、空间和状态
index_data        关键词、向量、实体和缓存
operational_data  任务、审计、日志和指标
credentials       外部服务凭据
```

凭据不得进入记忆、普通元数据、导出包和日志。

## 3. 保留策略

保留策略可按空间、来源和数据类型定义：

```text
keep_forever
expire_after_duration
archive_after_duration
purge_after_duration
keep_until_task_complete
manual_only
```

原始事件、记忆版本、审计和备份可以有不同保留期。派生索引不需要比权威数据保留更久。

## 4. 数据外发

外部处理前检查：

- 该空间是否允许外发。
- 该数据类型是否允许外发。
- 是否可以只发送必要片段。
- 是否包含敏感标记。
- 外部模型身份和处理版本是否已记录。

审计记录哪些事件或内容引用被发送，不默认记录完整外发内容。

## 5. 完整架构删除范围

| 对象 | 立即停止检索 | 后台清理 | 审计保留 |
| --- | ---: | ---: | ---: |
| 当前投影 | 是 | 是 | 是 |
| 记忆版本 | 是 | 按策略 | 是 |
| 原始事件 | 按模式 | 是 | 可保留最小元数据 |
| 原始内容和附件 | 是 | 是 | 否 |
| 关键词和向量索引 | 是 | 是 | 否 |
| 实体、关系和缓存 | 是 | 是 | 否 |
| 等待任务 | 取消 | 是 | 是 |
| 普通日志 | 避免含内容 | 按保留期 | 可选 |
| 备份 | 否 | 到期或重写 | 最小记录 |

## 6. 第一阶段删除模式

```text
memory_only      将单条记忆设为 deleted，并在同一事务删除 FTS 记录
```

第一阶段删除请求返回当前记忆状态。以下能力延期：

```text
source_and_memory
space_purge
account_purge
physical_purge
```

第一阶段 raw event、revision、state event、evidence 和 audit 继续保留。删除不承诺回收 SQLite 文件空间。

## 7. 证据和派生记忆

后续支持删除原始事件时，依赖该事件的记忆需要：

- 删除相应证据关联。
- 重新评估是否仍有足够证据。
- 无证据时撤回、删除或标记待复核。
- 重建相关索引和高层摘要。

不能保留无法解释来源的“孤儿权威记忆”而不标记状态。

## 8. 导出和备份

- 导出受当前删除和敏感性策略约束。
- 备份必须受到与权威数据相同的文件访问保护。
- 删除数据在旧备份中可能持续到备份到期，API 必须明确说明。
- 恢复旧备份后必须重新执行删除记录或清理清单，避免已删除数据重新出现。
